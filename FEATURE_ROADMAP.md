# OmniCam AI — OBS-style feature roadmap

## Alpha (current implementation)
- Image/video media picker, preview, image filters, text overlays, image export

## Planned (not yet implemented)
- Scene collections, source list, scene/source layering and transform controls
- Camera/microphone input, permissions, capture session lifecycle
- Media source playback, image slideshow, chroma key, backgrounds, text, shapes
- Audio mixer with independent volume, mute, monitoring and meters
- Video recording, encoding presets, resolution/FPS settings, local export
- Live streaming via user-provided RTMP endpoints and service-approved APIs
- Transitions, hotkeys/quick actions, studio preview/program mode
- Performance metrics, dropped-frame reporting, crash handling
- Explicit consent-based avatars/effects, no deceptive impersonation

## Compatibility testing (unverified)
- WorldTalk, WhatsApp, Messenger, Instagram and other apps do not necessarily accept third-party camera streams.
- Systemwide virtual camera is not part of this alpha. No root or system changes are required.

OBS Studio is open source (GPL-2.0-or-later); reuse of its source would require license compliance and attribution. This project currently uses independently written source.
